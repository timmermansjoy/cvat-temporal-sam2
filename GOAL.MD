# SAM2 Temporal Tracking Goal

Last updated: 2026-07-24

## Goal

Make accurate video labeling feel like one continuous interaction:

1. Identify an object with positive and negative points.
2. See its mask update after every click.
3. Propagate five frames backward or forward with one nearby key.
4. Review predictions frame by frame.
5. Correct a mask and use that correction as a new temporal anchor.
6. Repeat without reopening a modal or reselecting the object.

Success means an annotator uses the mouse only to identify or correct the object
and keeps one hand on the `S D F G` row for the rest of the sequence.

## Product contract

### Interactive mask

- Left click adds a positive point.
- Right click or a configurable modifier-click adds a negative point.
- The current-frame mask updates after every point.
- Undo removes the latest point.
- `Enter` accepts only the current frame.
- `Esc` cancels the interaction.
- Existing polygons and masks can also seed tracking.
- When an unlocked mask is selected, the point interactor refines that mask
  instead of creating a new object.

### Keyboard workflow

| Key | Action |
| --- | --- |
| `S` | Propagate SAM2 five frames backward |
| `D` | Navigate one frame backward |
| `F` | Navigate one frame forward |
| `G` | Propagate SAM2 five frames forward |
| `Enter` | Confirm the selected mask on the current frame |
| `C` / `V` | Keep CVAT's ten-frame navigation |

- Shortcuts use CVAT's native shortcut registry and remain configurable.
- Propagation happens only after an explicit `S` or `G` command.
- `G` predicts frames `N+1` through `N+5`, then opens `N+1`.
- `S` predicts frames `N-1` through `N-5`, then opens `N-1`.
- The tracked object stays active after navigation.
- Commands skip unavailable frames and stop cleanly at task boundaries.
- `S` and `G` immediately show a non-blocking directional progress bar, update
  it during initialization and propagation, then replace it with a compact
  success, warning, or failure result.

### Predictions and corrections

Each mask has one behavioral state:

- **Predicted:** generated by SAM2 and safe to replace.
- **Confirmed:** accepted by a human and never replaced automatically.
- **Corrected:** edited by a human, protected, and used as a temporal anchor.

When a mask is corrected:

- The correction conditions subsequent SAM2 propagation.
- Pressing `G` regenerates up to five unconfirmed forward predictions.
- Pressing `S` regenerates up to five unconfirmed backward predictions.
- Confirmed and corrected annotations are never overwritten.
- Each propagation is one undoable CVAT action.
- If an object reappears as a separate mask segment, CVAT's native `M` merge
  workflow joins the before/after segments into one mask track.
- The merged track has one visible CVAT ID, preserves per-keyframe prediction
  sources, and can immediately continue with `S` or `G`.
- Cross-job semantic group IDs remain internal; annotators do not edit or see a
  second identity number.

### Jobs and concurrency

- The interaction is frame-by-frame even when a task contains multiple jobs.
- Propagation may cross job boundaries when permissions and task layout allow it.
- Independent jobs, videos, and objects may run concurrently.
- Frames in one temporal chain remain ordered because later predictions depend on
  earlier temporal memory.
- Results may stream into jobs as they finish, but partial failures must not
  partially commit a five-frame operation.

### Reliability

- SAM2 state is bound to the current task, job, object, and direction.
- Repeated propagation retains temporal memory; it does not initialize from
  scratch on every key press.
- A failed or cancelled operation changes neither annotations nor tracker state.
- Expired state can be rebuilt from the nearest confirmed or corrected anchor.
- Multi-object state updates are committed atomically.
- Deleted, excluded, or inaccessible frames are handled consistently.
- The shortcut is inactive when SAM2 is unavailable or no compatible object is
  selected.

### Model strategy

- [x] SAM2.1-tiny remains the default CPU backend.
- [~] SAM 3.1 is the intended optional CUDA backend for joint multi-object
  propagation, but it is not wired into `S`/`G` yet. Meta's current public
  multiplex API requires a fixed video resource, does not expose an existing
  mask as a high-level prompt, has gated weights, and has no tagged software
  release. Its advertised speedup comes from batching many tracked objects on
  CUDA, so it does not imply a similar gain for one selected object over a
  five-frame window. A frame-at-a-time compatibility wrapper would lose both
  corrected-mask fidelity and multiplexing, so it is deliberately not shipped.
- [ ] Add the SAM 3.1 backend after its adapter can preserve exact mask anchors
  and temporal memory over CVAT's five-frame windows, then benchmark it on the
  intended production CUDA hardware.

## Implementation checkpoints

### 1. Stabilize the existing foundation

- Keep one SAM2 action-registration path.
- Make multi-object state advancement atomic.
- Add the smallest protocol test that proves initialization, temporal advancement,
  task isolation, and failure safety.
- Separate SAM2 integration changes from optional local lifecycle conveniences.

Exit condition: existing forward batch tracking is deterministic, failure-safe,
and covered by one runnable protocol check.

### 2. Add persistent directional sessions

- Give a session an object identity, direction, anchors, and temporal memory.
- Support forward and reverse propagation without reinitializing each command.
- Propagate at most five frames per request.

Exit condition: starting at a middle frame can produce five accurate frames in
either direction while retaining memory between repeated commands.

### 3. Add the frictionless keyboard loop

- Register configurable `S` and `G` shortcuts through CVAT.
- Keep `D`, `F`, `C`, and `V` navigation behavior intact.
- Keep the object selected and open the first prediction after propagation.
- Remove modal-only choices from the primary frame-by-frame path.

Exit condition: an annotator can review a sequence using the `S D F G` row
without reopening a dialog.

### 4. Add live prompting and correction

- Reuse an existing CVAT/SAM interaction path where possible.
- Update the current mask after each positive or negative point.
- Treat edited masks as protected temporal anchors.
- Invalidate and regenerate only dependent, unconfirmed predictions.

Exit condition: a correction on any frame improves subsequent propagation in
both directions without overwriting human-approved work.

### 5. Extend across jobs

- Coordinate sessions and commits at task level.
- Run independent work concurrently within available GPU capacity.
- Preserve ordered inference inside each temporal chain.
- Surface compact task/job progress and recoverable failures.

Exit condition: one interaction can continue across all permitted jobs without
annotation loss or job-boundary accuracy regressions.
